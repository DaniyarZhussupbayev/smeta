# Смета за 5 минут

Веб-приложение для быстрого составления смет и коммерческих предложений с сохранением в PDF.

Для кого:
- предприниматели — подготовить коммерческое предложение клиенту;
- офисные сотрудники — составить смету закупки или список расходов для руководителя.

## Файлы приложения

- `index.html` — структура страницы: поля документа, позиции сметы, итог и кнопки действий.
- `styles.css` — оформление страницы, удобное отображение на телефоне и стили для сохранения в PDF.
- `script.js` — обработка ввода, расчёт стоимости позиций и общей суммы, действия с документом и сохранение в PDF.

На этом этапе созданы только `README.md` и `AGENTS.md`. Файлы приложения будут добавлены по отдельному запросу.

## Как открыть

После создания файлов приложения откройте `index.html` двойным щелчком. Приложение должно работать прямо в браузере, без установки программ и запуска сервера.

## Как проверить

После реализации расчёта добавьте две позиции:

1. Количество — 2, цена — 15 000 ₸. Стоимость позиции — 30 000 ₸.
2. Количество — 1, цена — 8 000 ₸. Стоимость позиции — 8 000 ₸.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.
